# Study Sync Platform Build

## Experience
- Establish a dark-first liquid-glass design system with spectral lighting, precise typography, frosted navigation, and motion that remains lightweight.
- Build a shared responsive shell with desktop navigation, mobile menu, account-aware actions, and a polished footer.

## Public Pages
- Home: interactive dashboard preview, audience benefits, AI demonstrations, platform sync, screenshot devices, testimonials, and FAQ.
- Features: dedicated Student, Parent, and Teacher workflows with realistic lecture, note, assignment, explanation, and analytics previews.
- Downloads: macOS available state plus Windows, Android, and iPhone roadmap states; include version, release notes, changelog, and requirements.
- About: mission, vision, origin story, four-phase timeline, roadmap, and future plans.
- Contact: working contact, feedback, and bug-report modes with clear success states.
- Privacy and Terms: complete, readable policy pages with route-specific metadata.

## Accounts and Profiles
- Build email/password login, Google sign-in, registration, email confirmation, password recovery, and reset-password flows.
- Registration adapts to Student, Parent, or Teacher details and creates a secure saved profile.
- Add a protected profile dashboard with role-specific metrics and editable identity details.
- Keep account navigation session-aware and clear protected data on sign-out.

## Technical Details
- Use TanStack Start routes, React, TypeScript, Tailwind v4 tokens, existing UI primitives, and Lucide icons.
- Store profiles in Lovable Cloud with row-level access limited to each signed-in user.
- Give every public page unique title, description, Open Graph metadata, Twitter card metadata, and appropriate structured data.
- Validate desktop, tablet, and mobile layouts in the running preview and resolve build/runtime issues.
